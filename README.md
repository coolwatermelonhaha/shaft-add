# Shaft Additionality

A browser-based voxel sandbox game built with Three.js.

---

## What is this?

Shaft Additionality is a Minecraft-inspired voxel sandbox that runs entirely in your browser. Mine blocks, craft tools, smelt ores, and build whatever you can imagine. Watch out for the cursed cows.

Part of the **Additionality** universe — eventually expanding with food, farming, and other systems from the *Food Additionality* Minecraft mod.

## Where to play?

You can join the game by [clicking here](https://coolwatermelonhaha.github.io/shaft-add/dist/).

## Features

- **Voxel world** generated from procedural noise — biomes, caves, ores
- **Survival + Creative modes** — switch anytime with `U`
- **Mining & crafting** — 2×2 and 3×3 crafting grids with swipe-to-place
- **Tools** — wooden and stone pickaxes/axes with durability
- **Ores** — coal and iron with proper vein generation
- **Furnace** — smelt raw iron into ingots using coal or wood as fuel
- **Day/night cycle** — dynamic sun, moon, and sky colors
- **Cursed cows** — they exist. They're wrong. We love them.
- **Flying in creative** — double-tap SPACE

## How to play

### Controls
| Key | Action |
|---|---|
| WASD | Move |
| Mouse | Look around |
| SPACE | Jump (double-tap in Creative to fly) |
| SHIFT | Sneak |
| CTRL | Sprint |
| Left-click | Break block / hit mob |
| Right-click | Place block / use item / open chest |
| 1–9 | Select hotbar slot |
| E | Open inventory |
| U | Open gamemode menu |
| M | Toggle music |

### Getting started
1. Break some wood with your bare hands
2. Craft planks, then sticks, then a wooden pickaxe
3. Mine stone to get cobblestone
4. Craft a furnace
5. Mine iron ore, smelt raw iron into ingots
6. Keep going — build a base, dig to the bottom, find caves

## Running locally

*(Only needed if you want to run the game from the downloaded files instead of the live link above.)*

The game needs to be served from a local web server so the browser can load textures and sounds.

### Requirements
- Python 3 — [download here](https://python.org/downloads)
  - During install, check **"Add Python to PATH"**

### Steps
1. Download or clone this repo
2. Double-click **`starter_server.bat`**
3. The game opens in your browser
4. Close the black window to stop the server
